# 部署方案

> 本文档记录 NanoFleet 的部署方式。原型期目标是"零配置、单文件可运行"。

---

## 1. 部署方式清单

| 方式 | 适用场景 | 状态 |
| :--- | :--- | :---: |
| **单文件打包** | Python 原型期，打包为单可执行文件 | ⬜ |
| **systemd 服务** | Server / Agent 作为系统服务常驻 | ⬜ |
| **U 盘一键部署** | 校园网受限环境，Agent 免配置安装 | ⬜ |
| **一键安装脚本** | `curl \| bash` 拉取并安装 Agent | ⬜ |
